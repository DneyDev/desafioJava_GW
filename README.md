# Projeto do Módulo 3 - Fundamentos Java e Orientação a Objetos

O projeto abrange a modelagem das Classes principais: 
---
- Cliente
- Endereço
- Entrega
- Produto

Como também a definição de Atributos e Métodos.

Para testar, é só mudar os valores que estão como **'null'** para os desejados.
Exemplo: 

'cep: null' -> 'cep: 12345-678'
